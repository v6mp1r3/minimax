# Documente locale DocuGuide

Pune aici documentele pe care vrei să le folosească DocuGuide:

- PDF
- DOCX
- TXT
- MD
- JSON
- CSV

DocuGuide le caută local înainte de răspunsul AI. Nu este nevoie să modifici codul.

Recomandare: pentru documente administrative, păstrează și numele instituției/procedurii în numele fișierului.
Exemplu: `CNAM_polită_medicală.md`, `ASP_inregistrare_SRL.pdf`.
